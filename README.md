# YouInsight AI Studio - 全能实时情报与智能研报工作台

基于 **You.com Web Intelligence API** 构建的现代化实时网络情报、深度研报、企业财报与正文提取在线工作台。

---

## 🌟 核心功能模块

1. **📰 行业情报早报 (Intelligence Digest)**
   - 组合实时检索与多源交叉分析，一键生成结构化行业动态、大事件简报与相关新闻来源列表。
2. **🧠 深度研报生成 (Deep Research)**
   - 针对复杂课题（技术方案、产业趋势、技术对比）进行多轮深度检索与总结，自带严格的真实出处标注（[[1]], [[2]]）。
3. **🔍 实时联网搜索 (Live Web Search)**
   - 纯净、无广告的高信噪比网页检索，提取精准标题、文本片段及页面时间戳，支持一键针对搜索结果发起深度研报。
4. **📈 企业财报与金融分析 (Financial Intelligence)**
   - 穿透 SEC 官方披露文件与财报，精准比对营收增长、利润率及业务拆解数据。
5. **📑 网页干货内容提取 (Contents Reader)**
   - 自动去除广告、弹窗与多余样式，一键提取目标网页的干净正文 Markdown / HTML。
6. **⚡ 动态 API 配置与延迟诊断**
   - 支持在线更换自定义 API Key 并实时测试连接状态与延迟。

---

## 🚀 启动与使用

工作台后端基于 FastAPI 构建，运行于本机 127.0.0.1:8000：

`ash
# 启动命令（当前已在后台自动运行）
py -m uvicorn server:app --host 127.0.0.1 --port 8000
`

打开浏览器访问：**[http://127.0.0.1:8000](http://127.0.0.1:8000)** 即可开始使用。
